# RISC-V register diagrams

The diagrams are made in [Typst](https://typst.app/) using [RIVET](https://typst.app/universe/package/rivet).

> [!WARNING]
> Make sure to install the [CaskaydiaCove Nerd Font Mono](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/CascadiaCode.zip) font, or change the `default-font-family` parameter in [`common.typ`](common.typ).  
>
> More info:
> - [Typst docs](https://typst.app/docs/reference/text/text/#parameters-font)
> - You can check out your system fonts using `typst fonts`.
